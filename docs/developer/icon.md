# Mutant Video Producer icon

The selected icon is a symmetrical, pointed hexagonal reactor emblem in neon green
and cyan/blue. Iridescent glass and fine glitches surround a clean central play symbol.

The canonical RGBA source is `data/mvp-icon.png`; `data/mvp.ico` contains
16, 24, 32, 48, 64, 128 and 256 pixel versions for Windows. The PNG is embedded
as a Qt resource for application windows on Windows and Linux. The Windows executable
and installer use the ICO. ICO packaging preserves the source's transparency.

## Design provenance

See the [README screenshot recipe](screenshots.md) for refreshing the surrounding application imagery.

Created with built-in image generation: the Mutant Reactor silhouette was combined
with Holographic Glitch styling, then refined for symmetry, optical alignment and
an uncluttered center. The final asset was chosen by the user.
