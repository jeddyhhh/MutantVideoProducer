# Keyboard Shortcuts

**Options > Keyboard Shortcuts...** lists every command. Double-click one to give it a key. A key
already in use can be moved to the new command. **Reset All** brings back the defaults.

## Playback and moving around

| Key | Action |
|---|---|
| Space | Play / stop (stopping returns to where you started) |
| Enter | Play / pause in place |
| Shift+Space | Play from the start |
| J / K / L | Shuttle backwards / stop / forwards (again: 2x, 4x, 8x) |
| ← / → | Previous / next frame |
| Ctrl+← / Ctrl+→ | Previous / next edit point |
| Home / End | Go to the start / end |
| [ / ] | Previous / next marker |
| ↑ / ↓, or mouse wheel over the time ruler | Zoom in / out |
| Mouse wheel | Scroll the tracks up and down |
| Ctrl+0 | Zoom to fit |
| Ctrl+wheel or Shift+wheel | Scroll sideways |
| Q | Loop playback |

## Editing

| Key | Action |
|---|---|
| S | Split at the cursor |
| Del / Ctrl+Del | Delete / ripple delete |
| Ctrl+X / Ctrl+C / Ctrl+V | Cut / copy / paste at the cursor |
| Ctrl+A | Select all |
| G / U | Group / ungroup |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Alt+← / Alt+→ | Nudge the selection 1 frame (Shift+Alt: 10 frames) |
| Alt+[ / Alt+] | Trim the start / end to the cursor |
| I / O | Start / end of the time selection |
| M | Marker at the cursor (or where playback is) |
| R | Region from the time selection |
| Shift+F | Freeze frame at the cursor |
| Alt+Shift+F | Freeze frame in place (holds over what follows, nothing moves) |
| Ctrl+L | Auto ripple on / off |
| F8 | Snapping on / off (hold Shift while dragging to bypass it) |
| V / P | Volume (or composite level) / pan envelope on the selected track |
| Shift+V | Speed ramp on the selected events |

## With the mouse

| Mouse | Action |
|---|---|
| Ctrl+drag an event | Copy it |
| Ctrl+drag an edge | Change speed (time-stretch) |
| Alt+drag an event | Slip the footage inside it |
| Ctrl+Alt+drag an event | Slide it between its neighbours |
| Ctrl+Alt+drag a cut | Roll it (trim adjacent) |
| Shift+drag in empty track space | Time selection |
| Drag in empty track space | Box selection (Ctrl: add to it) |
| Alt+click a freehand mask | Add or remove a point |

| Ctrl+I | Import media |

| Ctrl+R | Render As |

| Ctrl+T | Insert text / title at the cursor |
| Ctrl+E | Event FX of the selected event |
| Ctrl+Shift+P | Event Pan/Crop |

| Ctrl+G | Group the selected devices into a rack (device chain) |
| Ctrl+B | Detect Beats |
| Ctrl+Shift+T | Auto Captions |
| Ctrl+Alt+S | Video scopes |
| Ctrl+Shift+M | Audio Mixer |
| 0-5 (Project Media) | Rate the selected files |

## The Keyframe Editor

| Key | Action |
|---|---|
| 1-9 | Curve after the picked keyframes: Linear, Hold, Smooth, Ease In, Ease Out, Ease In/Out, Bezier, Bounce, Elastic |
| ← / → (Shift: 10) | Move the picked keyframes a frame |
| ↑ / ↓ (Shift: 10%) | Graph: raise or lower their values by 1% of the range |
| K | Keyframe at the cursor on the settings worked on |
| Delete | Delete the picked keyframes |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste at the cursor |
| Ctrl+A / Esc | Pick all / none |
| G | Dope Sheet / Graph |
| F | Show everything |

## The Live tab

| Key | Action |
|---|---|
| Space | Start / stop |
| 1 2 3 4 / Q W E R / A S D F / Z X C V | Play the 16 pads (hold for momentary pads) |
| Shift+click a pad or scene | Cue it |
| B | Set 1 (the first beat of a bar) |
| F1-F8 | Recall scenes |
| Page Down / Page Up | Next / previous setlist song |
| Enter / Shift+Enter | Switcher: Cut / Auto |
| F11, double-click | Full screen (Pop Out window) |
| Esc | Leave full screen |
